## Hardware and tools

- **[AK820 Pro Modder](https://github.com/wsclx/ak820pro-modder)**: open-source control software for the Epomaker / Ajazz AK820 Pro keyboard, made for macOS first. Lighting, keymap, macros, per-key RGB and the built-in display.
